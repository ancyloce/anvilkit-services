# Typography

## Typefaces

Body text uses Inter at 16 pixels. Headings use Lora, a serif typeface, in semibold weight.

## Type scale

The type scale follows a ratio of 1.25: 16, 20, 25, 31 and 39 pixels. Captions use 13 pixels.

## Line height

Body text uses a line height of 1.5. Headings use a line height of 1.2 and never wrap to more than three lines.
