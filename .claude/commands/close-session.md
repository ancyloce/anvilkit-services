# Close the Session

When the user explicitly invokes `/close-session`:

1. Follow [AGENTS.md](../../AGENTS.md), including its [Project memory policy](../../AGENTS.md#project-memory).
2. Execute the [shared checkpoint workflow](../../AGENTS.md#memory-checkpoint) once in closeout mode. At its recovery step, apply [Closeout readiness](../../AGENTS.md#memory-closeout).
3. Finish with that workflow's report-and-stop step, including the assessed readiness and any gaps.

Use the shared workflow's scope and draft-only handling; this command adds no permissions or separate memory rules.
